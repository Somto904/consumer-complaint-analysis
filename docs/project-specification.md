# Project Specification

## Project Name

FinSight: Consumer Complaint Analysis & Visualization Tool

## Purpose

FinSight is a full-stack web application that helps users analyze and visualize public consumer financial complaint data from the CFPB.

The goal is to make large complaint datasets easier to understand through filters, charts, summary cards, and tables.

## Target Users

- Consumers comparing financial companies or products
- Students and researchers studying complaint trends
- Data analysts working with public financial data
- Recruiters reviewing a full-stack portfolio project

## Version 1 Scope

Version 1 will include:

- Dashboard summary cards
- Complaint data table
- Filters by company, product, state, and issue
- Charts for top companies, products, complaint trends, and timely responses
- Java Spring Boot backend API
- PostgreSQL database
- React frontend dashboard

## Future Features

- Company comparison
- State comparison
- Advanced search
- Export filtered data
- Complaint narrative analysis
- Python-based analysis scripts

## Tech Stack

- Java Spring Boot
- React
- PostgreSQL
- CFPB Consumer Complaint Database
